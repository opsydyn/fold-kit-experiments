In relational programming you describe how values relate, and a search finds the values that satisfy the relation, in any direction. miniKanren is the best-known family: the same relation can append two lists or split one.

It stays in Assess. It is rarely the whole solution, but it is a useful way to think about type inference, program synthesis and puzzles, and it pairs well with generated candidates that need checking.
