Codex is OpenAI's coding agent, with an open-source terminal client that reads a repository, runs commands and proposes changes. It covers much of the same ground as Claude Code, and having two capable agents keeps comparisons honest.

It moved from Assess to Trial in the fourth edition, after use on real repository tasks. The same rules apply as for any agent: give it the project's checks, scope its permissions, and review what it produces before it lands.
