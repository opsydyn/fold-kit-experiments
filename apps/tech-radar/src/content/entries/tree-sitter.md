Tree-sitter builds concrete syntax trees incrementally, updating them as you type, with grammars for most languages. Editors use it for highlighting and navigation, and tools use it for structural search, code maps and refactoring.

It has been in Adopt since the first edition. Use it whenever a tool needs to understand code structure rather than match text, including building context for coding agents.
