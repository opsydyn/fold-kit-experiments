Pi is a composable agent toolkit with a coding CLI and a terminal interface. It treats an agent as parts you can assemble and change, rather than one fixed product.

It joined the radar in Trial in the fourth edition. It is a useful alternative to Claude Code and Codex where you want to shape the agent's tools and loop yourself. The same review and permission rules apply.
