Lean is both a programming language and a proof assistant: you write a program and machine-checked proofs about it in the same language. Mathlib, its mathematics library, shows what large-scale formal proof looks like.

It stays in Assess. It is most interesting next to AI tools: a model can suggest proof steps, and Lean checks them, so a proof is evidence rather than a plausible argument. See _Proof-guided generation_.
